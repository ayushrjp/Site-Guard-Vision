# SiteGuardVision — Project Cleanup Plan

Prepared before any deletion, as required. This document lists what will be
removed, why it is safe, and what is deliberately preserved or flagged for
manual review.

Audit date: 18 November 2026
Project root: `C:\Users\ayush\Downloads\SiteGuardVision`

---

## 1. Method

1. Inventoried every file outside `.venv`.
2. Searched Python sources, templates, JavaScript, tests and configuration for
   references to each candidate (`grep` for filenames, imports and URL paths).
3. Excluded anything that is user data, a bundled asset, a model checkpoint, a
   sample video, a required report or a runtime dependency.
4. Classified each candidate as **safe to delete**, **preserve**, or **manual
   review**.
5. No extension-wide deletion (no `*.jpg`, `*.mp4`, `*.db`, `*.py`) was used.

## 5. Dependencies

`requirements.txt` is audited, not pruned:

- `lapx==0.13.1` is **required** by ByteTrack and was previously missing.
- `gunicorn==23.0.0` is **required** for Render; it is POSIX-only, so Windows
  developers continue to use `python server.py`.
- `flask`, `ultralytics`, `pillow`, `chromadb`, `pypdf`, `requests` are all
  imported by the application.

No dependency is removed, because every listed package is used.
